# 10+ Minecraft Launcher

**[⬇ Download the latest version](https://github.com/TimTamno1/10plus-launcher/releases/latest)** — grab `10PlusLauncher-Setup-x.y.z.exe` and run it.

- Windows 10/11, 64-bit
- Sign in with your Microsoft account, pick a version, press **Launch**.
- The launcher updates itself: when a new version is out it downloads automatically and you restart into it.

Windows may show "Windows protected your PC" the first time — click **More info → Run anyway**.
